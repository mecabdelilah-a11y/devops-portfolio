# Terraform Local Project

This project is an introduction to Infrastructure as Code (IaC) using Terraform. It demonstrates how to use a local provider to create a file on the machine, simulating the workflow of creating infrastructure in the cloud.

## What it demonstrates
- Writing a Terraform configuration file (`main.tf`).
- Initializing a Terraform project (`terraform init`).
- Previewing changes (`terraform plan`).
- Applying changes (`terraform apply`).
- Destroying infrastructure (`terraform destroy`).

## How to run it
```bash
terraform init
terraform plan
terraform apply
terraform destroy
